## Daynote · 업무 및 일정 캘린더

월간 캘린더와 날짜별 일정·TODO List를 제공하는 오프라인 데스크톱 앱입니다.

Node.js 22.12 이상에서:

```sh
npm ci
npm start
```

Windows 설치파일은 `npm run dist:win`으로 빌드합니다.
