# 첫 버전 요구사항

기존 `plan.txt`, `images/main.png`, `images/idea.png` 및 사용자와 합의한 내용을 기준으로 작성했습니다.

## 앱 형태

- Windows에서 실행되는 설치형 데스크톱 앱.
- 다른 운영체제로 확장 가능한 구조.
- 일반 창처럼 크기 조절·최소화·최대화 가능.
- 사용자가 Windows 작업표시줄에 고정 가능.
- Windows 로그인 후 자동 실행을 설정에서 켜고 끄기.
- 마지막 창 크기와 위치 복원.
- 설치 후 인터넷 연결 없이 사용.

## 화면

- 왼쪽은 월간 캘린더.
- 오른쪽은 선택한 날짜와 일정, TODO List.
- 일정 영역은 TODO List보다 작게 배치.
- 달 이동과 오늘 날짜 이동.
- 월간 날짜 칸에 일정 제목 표시. 긴 제목은 말줄임.
- 일정이 칸을 넘으면 `+N개`로 숨겨진 수 표시.
- 날짜 칸 하단에 `완료 2/전체 5` 형식의 할 일 진행률 표시.

## 입력과 데이터

- 일정과 할 일 모두 체크박스 입력.
- Enter는 새 체크박스 생성.
- 새 항목에서 Tab을 누르면 체크박스 없는 들여쓰기 설명으로 전환.
- 설명은 바로 위 체크박스 항목에 연결.
- 설명에서 Enter를 누르면 새 체크박스 생성.
- 너비를 넘는 글은 자동 줄바꿈.
- 완료 시 체크박스만 표시하고 취소선은 사용하지 않음.
- 날짜별 기록 보관 및 로컬 자동 저장.
- 미완료 업무 자동 이월은 구현하지 않음.
- 별도 회고·업무 일지 영역은 구현하지 않음.

## 구현상 기본값

- 앱 이름은 Daynote.
- 자동 실행은 기본 꺼짐.
- 일정 시각은 별도 필드 없이 텍스트로 자유롭게 작성.
- 앱 실행 시 오늘 날짜를 선택.
- 진행률은 내용이 있는 TODO 체크박스만 집계.
- 설명과 빈 항목은 진행률에서 제외.
- Shift+Tab으로 설명을 체크박스로 되돌릴 수 있음.
- 항목 삭제·마지막 삭제 실행 취소 제공.
- 외부 캘린더 연동, 로그인, 동기화, 알림, 반복 일정은 첫 버전에 포함하지 않음.
