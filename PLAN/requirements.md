# Daynote 요구사항

**기준 버전: 1.3.1** · [서비스 소개](../README.md) · [사용법](../docs/사용법.md) · [검증결과](../docs/검증결과.md)

이 문서는 초기 기획과 이후 사용자 피드백을 반영한 **현재 기능 명세**입니다. 초기 아이디어와 달라진 부분은 이 문서를 기준으로 합니다. 버전별 변경 내용은 검증결과 문서에 보관합니다.

## 목적과 사용 환경

- 회사에서 개인의 일정과 업무를 날짜별로 기록하는 데스크톱 앱.
- 출근 직후 업무 계획을 작성하고 퇴근 전 수행 내용과 완료 여부를 정리.
- Windows에서 실행되는 설치형 앱이며 현재 배포 대상은 Windows x64.
- 다른 운영체제로 확장 가능한 Electron 구조. Linux·macOS 빌드 설정은 있으나 현재 버전의 배포 검증은 별도.
- 설치 후 계정이나 인터넷 연결 없이 사용하고 기록은 로컬 파일에 저장.

## 데스크톱 동작

- 일반 창처럼 이동·크기 조절·최소화·최대화 가능.
- 실행 시 오늘 날짜를 선택하고 이전 창 크기·위치·최대화 상태를 복원.
- 이전 모니터가 사라지면 현재 모니터 안으로 위치를 보정.
- 사용자가 Windows 작업표시줄에 고정해 실행 가능.
- Windows 로그인 후 자동 실행을 설정에서 켜고 끄기. 기본값은 꺼짐.
- 자동 실행 설정은 설치된 Windows·macOS 앱에서 지원하고 개발용 실행과 Linux에서는 비활성화.

## 화면 구성

| 영역 | 요구사항 |
|---|---|
| 상단 | 작은 Daynote 아이콘과 이름을 세로 중앙 정렬. Export, 저장 상태, 설정 버튼 배치 |
| 왼쪽 | 월간 캘린더, 달 이동, 오늘로 이동 |
| 월 제목 | Daynote 이름과 같은 22px 크기 사용 |
| 오른쪽 위 | 선택한 날짜, 메모장 전환 버튼과 일정 카드 |
| 오른쪽 아래 | 일정 카드보다 큰 TODO List 카드와 진행률 |
| 전체 배치 | 캘린더와 기록 영역 사이 간격을 확보하고 작은 창에서도 입력·진행률·안내 문구를 확인 가능하게 배치 |

- 초기 부제 `나의 업무 캘린더`와 화면 하단의 두 홍보 문구는 표시하지 않음.
- 캘린더 패널 상단 오른쪽에 `일정만 표시`·`할일만 표시` 버튼을 배치하며 오른쪽 기록 영역을 침범하지 않음.
- 기본값은 일정만 표시. 두 버튼은 항상 하나만 선택되며 선택된 버튼을 다시 눌러도 해제하지 않음.
- 날짜·달 이동 시 표시 종류를 유지하고 앱 재실행 시 일정만 표시로 시작.
- 날짜 칸에는 선택한 종류의 내용 있는 체크박스 항목 제목만 입력 순서대로 표시. 설명·빈 항목은 제외하고 완료 체크도 반영.
- 긴 제목은 말줄임하고, 칸을 넘는 항목은 `+N개`로 표시. 하단 범례도 선택 종류에 맞게 변경.
- 두 표시 모드 모두 날짜 칸 하단에 할 일 진행률을 `완료 2/전체 5` 형태로 요약.
- 날짜를 선택하면 오른쪽에 해당 날짜의 전체 내용 표시.
- 장식용 영문 라벨 `MY CALENDAR`·`DAILY NOTE`·`PREFERENCES`는 표시하지 않음.
- 입력 본문 14px, 설명 13px, 오른쪽 진행률 12px, 체크박스 16×16px 사용.
- 추가 버튼 32×32px, 삭제 버튼 28×28px 사용. 체크 표시와 설명 글머리표는 본문과 세로 정렬.
- 밝은·어두운 테마의 보조 글자·입력 안내 대비를 확보하고 선택 날짜와 입력 포커스를 명확히 표시.
- 좁은 창에서는 키보드 안내를 줄바꿈. 화면 높이가 580px 이하이면 작업 영역 스크롤 허용.
- 선택한 날짜 제목 변경을 보조 기술에 알리도록 `aria-live` 적용.

## 일정·할 일과 설명 입력

- 일정과 TODO 모두 체크박스 항목으로 입력.
- 입력줄을 직접 클릭했을 때 편집 시작. 빈 공간을 클릭하면 편집을 종료하고 항목을 추가하지 않음.
- 새 항목은 Enter 또는 `(+)`로 추가. 여러 줄 붙여넣기는 줄별 체크박스로 처리.
- Enter 입력 시 커서 뒤 텍스트는 새 항목으로 이동.
- 새 체크박스 항목에서 Tab을 누르면 바로 위 체크박스의 들여쓰기 설명으로 전환.
- 설명은 가장 가까운 위쪽 체크박스에 연결. 첫 항목은 설명으로 전환할 수 없음.
- 설명에서 Enter를 누르면 새 체크박스 생성. 기존 설명 묶음은 원래 항목에 연결된 상태로 유지.
- Shift+Tab으로 설명을 체크박스 항목으로 전환.
- 글이 너비를 넘으면 자동 줄바꿈하며 설명도 하나의 항목으로 유지.
- 설명은 작은 원형 글머리표로 표시하고, 구분선은 체크박스와 연결된 설명 묶음 아래에 표시.
- 체크 시 취소선이나 순서 변경 없이 체크박스만 표시.
- `×`로 항목 삭제. 체크박스 삭제 시 연결된 설명도 함께 삭제.
- 키보드로 삭제 버튼을 실행하면 이전 입력줄로 포커스 이동. 남은 항목이 없으면 해당 카드의 추가 버튼으로 이동.
- 마우스로 삭제할 때는 다른 입력줄을 자동으로 편집 상태로 전환하지 않음.
- 삭제 알림과 삭제 실행 취소 기능은 제공하지 않음.
- 한국어 IME 조합 중이거나 조합 종료 직후 같은 Enter를 누르고 있는 동안은 항목 생성으로 처리하지 않음. 문장 중간의 수정 내용·커서를 유지하고 키를 뗀 뒤의 다음 Enter는 기존처럼 새 항목 생성.

## 메모장

- 날짜 옆의 `메모장` 버튼으로 오른쪽 일정·할 일 카드와 메모장 영역을 전환. 기본은 일정·할 일 카드.
- 메모장을 열면 날짜와 관계없는 전체 메모 목록을 표시. 날짜·달 이동 중에도 메모장을 유지.
- 메모장 버튼을 다시 누르면 일정·할 일 카드로 복귀. 다시 열면 목록 표시.
- `+`로 새 메모를 추가해 제목·본문 작성 화면을 열되 입력칸은 자동 포커스하지 않음. 기존 메모를 열 때도 동일. 클릭 또는 키보드 이동으로 입력칸을 선택한 뒤 편집.
- 제목은 한 줄 입력, 본문은 여러 줄 자유 입력. 목록에는 제목을 표시하고 공백뿐인 제목은 `제목 없음`으로 표시.
- 새 메모는 목록 맨 앞에 추가. 수정 시 순서는 유지하며 내용 없는 새 메모도 보존.
- 목록의 제목을 눌러 수정. `목록으로` 버튼으로 돌아오며 별도 저장 버튼 없이 자동 저장.
- `+` 옆 `−`로 선택 모드 진입. 여러 메모를 선택하고 `선택 삭제` 후 확인 창에서 삭제 또는 취소. 확인 취소·Esc는 내용과 선택을 보존하며 삭제 완료 시 목록으로 복귀.
- 빈 목록에서는 `−`, 선택이 없을 때는 `선택 삭제`를 비활성화. 선택 모드에서는 추가를 비활성화하고 `취소` 또는 `−` 재선택으로 모드 종료.
- 메모장 왼쪽 위 뒤로가기 버튼으로 일정·할 일 카드에 복귀하고 메모장 버튼의 선택을 해제. 선택 모드도 초기화.
- 목록 상단의 날짜와 관계없다는 안내 문구는 표시하지 않음.
- 기존 자동 저장·종료 시 저장·실패 시 재시도·백업·손상 복구에 전체 메모 포함.
- 메모 없는 기존 데이터와 호환하며 `calendar.json`의 최상위 `memos` 배열에 저장.
- 메모는 캘린더 날짜 칸·TODO 진행률·Excel 내보내기에 포함하지 않음.
- 긴 제목·본문은 패널 안에서 줄바꿈·스크롤하며 작은 창과 모든 기존 테마에서 사용 가능.

## 진행률

- 내용이 있는 TODO 체크박스 항목만 전체 개수에 포함.
- 체크한 TODO 개수로 완료 수·완료율을 계산.
- 일정·설명·빈 항목은 TODO 진행률에서 제외.
- 미완료 업무는 원래 날짜에 남기고 자동 이월하지 않음.

## Excel 내보내기

### 사용 흐름

- 자동 저장 문구 왼쪽에 **Export** 버튼 배치.
- 버튼을 누르면 설명과 시작일·종료일, 취소·Export 버튼을 포함한 팝업 표시.
- 설명: `내가 했던 업무 내용(TODO List)들을 엑셀로 정리하여 내보낼 수 있습니다.`
- 기본 기간은 현재 표시 중인 달의 첫날부터 마지막 날.
- Export를 누르면 저장 위치·파일 이름을 선택하고 실제 `.xlsx` 파일 생성.
- 기본 파일 이름: `Daynote_TODO_시작일_종료일.xlsx`.

### 데이터 규칙

| 열 | 규칙 |
|---|---|
| 날짜 | 실제 완료 시각이 아닌 TODO의 캘린더 날짜 |
| 업무 내용 | 항목 제목과 연결된 설명. 설명은 같은 셀에 줄바꿈과 글머리표로 표시 |
| 상태 | 내보내는 시점에 체크되어 있으면 `완료`, 아니면 `미완료` |

- 시작일·종료일을 모두 포함한 기간의 모든 TODO를 내보냄.
- 최신 날짜부터 나열하고 같은 날짜의 입력 순서는 유지.
- Schedule은 제외. 제목과 설명이 모두 비어 있는 항목은 제외하되 설명만 있는 항목은 보존.
- 자동 저장 대기 중인 최신 입력도 반영.
- 첫 행 고정, 열 필터, 내용 셀 줄바꿈 적용.
- 생성 자체에 인터넷이나 Excel 설치가 필요하지 않음.
- 잘못된 기간과 빈 기간은 팝업에서 안내하고 저장 취소·실패 후 재시도 가능.
- Excel 행·셀 글자 수 제한을 넘으면 기간 또는 내용을 조정하도록 안내.
- 내보내기로 기존 캘린더 기록과 체크 상태를 변경하지 않음.

## 테마·글꼴·작성자 표시

- 빨강·주황·노랑·초록·파랑·남색·보라·밝음·어두움의 9가지 테마.
- 기본 테마는 초록. 선택 즉시 화면에 적용하고 재실행 시 복원.
- 어두운 테마에서는 카드·입력란·설정 창·Export 팝업까지 함께 적용.
- 앱 내부 글꼴은 동봉된 Pretendard Variable Medium(500)으로 통일.
- 운영체제의 제목 표시줄과 설치 마법사 글꼴은 OS 설정을 따름.
- 설정 하단에 현재 버전과 `Crafted by ks0108.choi` 표시.

## 저장과 복구

- 일정·할 일·설명을 날짜별 로컬 데이터에 자동 저장하고 재실행 시 복원.
- 저장 상태를 상단에 표시하고 실패 시 클릭으로 재시도.
- 정상 종료 직전 입력을 저장하며 저장 실패 시 창을 유지하고 안내.
- `calendar.json`과 직전 정상 저장본 `calendar.json.bak` 관리.
- 손상 파일은 보존하고 정상 백업으로 복구. 복구 불가능할 때 기존 기록을 덮어쓰지 않고 종료.
- 메모는 날짜별 기록과 같은 `calendar.json`에 저장하고 재실행 시 복원.
- 테마는 `preferences.json`, 창 상태는 `window-state.json`에 분리해 저장.
- Excel 파일은 임시 파일을 완성한 뒤 대상 경로로 옮겨 저장.

## 현재 범위에 포함하지 않는 기능

- 미완료 업무 자동 이월, 별도의 회고·업무 일지 영역.
- 삭제 항목 복원, 여러 단계의 기록 버전 관리.
- 실제 완료 체크 날짜·시각 기록.
- 계정·클라우드 동기화·다른 캘린더와 연동.
- 알림·반복 일정·Excel 파일 가져오기.
