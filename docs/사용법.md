# Daynote 사용법

**기준 버전: 1.2.0** · [서비스 소개 및 개발 안내](../README.md) · [요구사항](../PLAN/requirements.md) · [검증결과](검증결과.md)

Daynote는 일정과 할 일을 날짜별로 기록하는 설치형 데스크톱 캘린더입니다. 출근할 때 하루의 계획을 적고, 퇴근 전에 완료 여부와 수행 내용을 정리하는 용도로 사용할 수 있습니다. 기록은 이 PC에 저장되며 설치 후에는 인터넷이나 계정 없이 사용합니다.

## 설치와 처음 실행

1. [최신 배포 페이지](https://github.com/chlrudtlr/Codex-Test/releases/latest)의 **Assets**에서 Windows x64용 `Daynote-Setup-1.2.0-x64.exe`를 다운로드합니다. 프로젝트에서 직접 빌드했다면 `dist/` 폴더에 있습니다.
2. 설치파일을 실행하고 마법사의 안내에 따라 설치 위치를 정해 설치합니다.
3. 시작 메뉴 또는 바탕화면에서 **Daynote**를 실행합니다.
4. 작업표시줄에 고정하려면 실행 중인 Daynote 아이콘을 우클릭하고 **작업표시줄에 고정**을 선택합니다.

일반 사용에는 Node.js나 Microsoft Excel 설치가 필요하지 않습니다. 현재 설치파일에는 코드 서명이 적용되어 있지 않습니다. 소스에서 실행하거나 설치파일을 직접 만들려면 [개발·빌드 안내](../README.md#개발-환경과-실행)를 참고하세요.

앱은 오늘 날짜로 열립니다. 마지막 창 크기와 위치를 기억하며 일반 프로그램처럼 이동·최소화·최대화·크기 조절이 가능합니다. 사용하던 모니터가 연결되지 않았다면 현재 모니터 안으로 창 위치를 보정합니다.

이전 설치파일은 [전체 배포 이력](https://github.com/chlrudtlr/Codex-Test/releases)에서 받을 수 있습니다. 각 버전에는 파일 일치 여부를 확인할 수 있는 `SHA256SUMS.txt`가 함께 제공됩니다. 설치할 때는 Assets의 `.exe` 파일을 선택하세요.

## 업데이트와 제거

### 업데이트

1. 작업 중인 내용의 상단 표시가 **자동 저장됨**인지 확인하고 Daynote를 종료합니다.
2. 새 버전의 설치파일을 실행해 기존과 같은 설치 위치에 설치합니다.
3. 다시 실행해 이전 기록과 설정을 확인합니다.

설치 폴더와 기록을 저장하는 사용자 데이터 폴더는 별도입니다. 다른 PC나 Windows 계정으로 옮길 때는 아래 [저장 위치와 백업](#저장-위치와-백업)의 절차를 사용하세요.

### 제거

Windows 설정의 설치된 앱 목록에서 **Daynote**를 찾아 제거합니다. 설치파일은 앱 제거 시 사용자 데이터 폴더를 자동 삭제하지 않도록 구성되어 있습니다. 필요한 기록은 제거 전에 별도로 복사해둘 수 있습니다.

## 화면 구성

| 위치 | 역할 |
|---|---|
| 왼쪽 월간 캘린더 | 날짜 선택, 달 이동, 일정 요약과 할 일 진행 현황 확인 |
| 오른쪽 위 날짜 | 현재 선택해 편집하는 날짜 확인 |
| 오른쪽 일정 카드 | 회의·행사·약속 등 일정 입력 |
| 오른쪽 할 일 카드 | 업무와 설명 입력, 완료 체크 및 진행률 확인 |
| 상단 Export | 기간을 지정해 TODO를 Excel로 내보내기 |
| 상단 자동 저장 표시 | 저장 상태 확인, 실패 시 다시 시도 |
| 상단 설정 아이콘 | 테마와 로그인 후 자동 실행 설정 |

일정 카드는 할 일 카드보다 작게 배치되어 있습니다. 오른쪽 카드의 내용은 선택한 날짜에 따라 바뀝니다.

## 날짜 선택과 캘린더

- 날짜를 클릭하면 오른쪽에서 해당 날짜의 내용을 편집합니다.
- 월 제목 옆 화살표로 이전·다음 달을 이동하고, **오늘** 버튼으로 오늘 날짜로 돌아갑니다.
- 달력의 날짜 버튼에 키보드 포커스가 있을 때 방향키로 날짜를 이동할 수 있습니다. 위·아래는 일주일씩 이동합니다.
- 날짜 칸에는 일정 제목이 표시됩니다. 긴 제목은 `…`으로 생략되고, 공간을 넘는 일정은 `+3개`처럼 숨겨진 개수로 표시됩니다.
- 날짜 칸 아래에는 할 일의 진행 상태를 `완료 2/전체 5` 형식으로 표시합니다. 날짜를 선택하면 전체 기록을 확인할 수 있습니다.

진행률은 **내용이 있는 TODO 체크박스 항목만** 집계합니다. 일정, 설명, 비어 있는 항목은 TODO 진행률에 포함하지 않습니다.

## 일정과 할 일 입력

입력줄을 직접 클릭해 작성합니다. 일정과 할 일 모두 같은 체크박스 입력 방식을 사용합니다. 일정의 시간은 `14:00 부서 회의`처럼 자유롭게 적습니다.

새 항목은 입력 중 `Enter`를 누르거나 카드의 `(+)` 버튼을 눌러 추가합니다. 빈 공간을 클릭하면 편집이 종료되며 입력란이 추가되거나 활성화되지 않습니다. 이미 비어 있는 마지막 체크박스가 있으면 `(+)` 버튼은 그 입력란으로 이동합니다.

### 키보드 사용법

| 키 또는 동작 | 결과 |
|---|---|
| Enter | 새 체크박스 항목 생성. 커서 뒤의 글은 새 항목으로 이동 |
| 새 항목에서 Tab | 위 체크박스 항목의 설명으로 전환 |
| 설명에서 Enter | 새 체크박스 항목 생성 |
| 설명에서 Shift + Tab | 설명을 체크박스 항목으로 전환 |
| 빈 항목에서 Backspace | 항목이 둘 이상인 경우 현재 빈 항목 삭제 |
| 여러 줄 텍스트 붙여넣기 | 줄별 체크박스 항목으로 추가 |

첫 항목은 연결할 상위 체크박스가 없으므로 설명으로 바꿀 수 없습니다. 설명은 가장 가까운 위쪽 체크박스에 연결됩니다. 기존 설명이 있는 항목에서 새 체크박스를 추가하면 설명 묶음 뒤에 생성됩니다.

다음은 입력 내용의 예시입니다.

```text
☐ 보고서 작성
    • 지난달 실적과 비교해 변경 사항 확인
☐ 회의 자료 준비
```

긴 글은 칸 너비에 맞춰 자동으로 줄바꿈됩니다. 설명도 화면에서 여러 줄로 보일 수 있지만 하나의 설명 항목입니다. 설명은 작은 원형 글머리표로 표시하며, 체크박스와 연결된 설명의 맨 아래에 구분선을 표시합니다.

### 완료 체크와 삭제

완료한 일정이나 할 일을 체크하면 체크박스만 바뀝니다. 취소선을 표시하거나 항목 순서를 바꾸지 않습니다. 미완료 업무도 기록한 날짜에 그대로 남고 다음 날로 자동 이동하지 않습니다.

항목 오른쪽의 `×` 버튼으로 삭제합니다. 체크박스 항목을 삭제하면 연결된 설명도 함께 삭제됩니다. 삭제 알림과 삭제 실행 취소 기능은 없습니다. `Shift + Tab`은 설명을 체크박스로 바꾸는 기능이며 삭제를 되돌리는 단축키가 아닙니다.

## Excel로 내보내기

1. 상단 자동 저장 표시 왼쪽의 **Export**를 누릅니다.
2. 팝업에서 **시작일**과 **종료일**을 선택합니다. 기본값은 현재 보고 있는 달의 첫날과 마지막 날입니다.
3. 팝업의 **Export**를 누릅니다.
4. 저장 창에서 파일 이름과 저장 위치를 지정합니다. 기본 파일 이름은 `Daynote_TODO_시작일_종료일.xlsx`이며 기본 저장 위치로 다운로드 폴더를 제시합니다.
5. 저장이 끝나면 내보낸 할 일 개수를 안내합니다.

파일 생성은 PC 안에서 이루어지므로 인터넷 연결이나 Excel 설치가 필요하지 않습니다. 생성한 파일은 `.xlsx`를 지원하는 프로그램에서 열어 확인할 수 있습니다.

### 출력 내용과 기간 기준

| 열 | 포함되는 내용 |
|---|---|
| 날짜 | 할 일을 기록한 캘린더 날짜, `YYYY-MM-DD` 형식 |
| 업무 내용 | 체크박스 항목과 연결된 설명. 설명은 같은 셀 안에 줄바꿈과 글머리표로 포함 |
| 상태 | 내보내는 시점의 체크 여부에 따라 `완료` 또는 `미완료` |

- 시작일과 종료일을 **모두 포함**합니다. 같은 날을 시작일·종료일로 지정해 하루만 내보낼 수도 있습니다.
- 선택한 기간의 **모든 TODO**를 포함합니다. 완료한 업무만 추리는 방식이 아닙니다.
- 최근 날짜부터 나열하며 같은 날짜 안에서는 입력 순서를 유지합니다.
- 일정(Schedule)은 제외합니다. 제목과 설명이 모두 비어 있는 항목도 제외합니다.
- 제목이 비어 있어도 설명이 있으면 그 설명을 보존합니다.
- 입력 직후 자동 저장 대기 중인 내용도 포함합니다.
- 실제 완료 체크 날짜나 완료 시각은 기록하지 않습니다. 과거 날짜의 업무를 오늘 체크해도 날짜 열은 원래 캘린더 날짜입니다.

첫 행에는 열 이름이 표시되며, 행을 스크롤할 때 제목을 볼 수 있도록 고정되어 있습니다. 각 열에 필터를 적용하고 업무 내용은 셀 안에서 줄바꿈되도록 구성했습니다.

### 빈 기간, 취소와 저장 오류

종료일이 시작일보다 빠르거나 날짜가 비어 있으면 팝업에서 수정 안내를 표시합니다. 기간에 내보낼 TODO가 없으면 파일을 만들지 않고 안내합니다.

저장 창에서 취소하면 선택한 기간을 유지한 채 다시 시도할 수 있습니다. 저장에 실패하면 다른 위치를 선택하거나, 덮어쓸 Excel 파일이 다른 프로그램에서 열려 있는지 확인한 뒤 다시 시도하세요. Excel의 행 수·셀 글자 수 제한을 넘는 경우에는 기간을 줄이거나 긴 항목을 나누도록 안내합니다.

Excel 내보내기는 업무 목록을 정리하는 출력 기능입니다. 앱 전체 기록과 설정을 옮길 때는 아래 데이터 폴더 백업 절차를 사용하세요.

## 테마와 글꼴

상단 설정의 **메인 테마**에서 빨강·주황·노랑·초록·파랑·남색·보라·밝은 테마·어두운 테마 중 하나를 선택합니다. 선택 즉시 적용되며 다음 실행에도 유지됩니다. 기본 테마는 초록입니다.

앱 내부 글꼴은 동봉된 **Pretendard Variable Medium(굵기 500)**입니다. PC에 따로 설치하거나 인터넷에서 글꼴을 불러올 필요가 없습니다. 운영체제가 그리는 제목 표시줄과 설치 마법사는 운영체제 글꼴 설정을 따릅니다. 출처와 라이선스는 [글꼴 안내](../src/fonts/README.md)에 있습니다.

설정 창 하단에서 앱 버전과 `Crafted by ks0108.choi` 문구를 확인할 수 있습니다.

## 로그인 후 자동 실행

설정에서 **로그인 후 자동 실행**을 켜거나 끕니다. 기본값은 꺼짐이며, 켜면 Windows 로그인 후 기억한 창 크기와 위치로 앱을 엽니다.

Windows에서는 설치된 앱에서 설정할 수 있습니다. 개발용 실행과 Linux에서는 스위치가 비활성화됩니다. macOS는 설치·서명 상태와 운영체제의 로그인 항목 허용에 따라 동작하며 별도 실사용 검증이 필요합니다.

자동 실행 여부는 운영체제의 시작 앱 설정에서도 바뀔 수 있으므로, 앱이 로그인 후 열리지 않으면 해당 설정도 확인하세요.

## 저장 위치와 백업

### 자동 저장

내용을 바꾸면 상단에 **저장 중**, 저장이 끝나면 **자동 저장됨**이 표시됩니다. 날짜를 바꾸거나 앱을 다시 실행해도 기록을 확인할 수 있으며, 정상 종료 시 마지막 입력도 저장합니다.

저장에 실패하면 상단에 **저장 실패 · 다시 시도**가 표시됩니다. 이 표시를 눌러 다시 저장할 수 있습니다. 정상적인 창 종료 중 저장에 실패하면 창을 열어두고 안내합니다.

### 파일 위치

정확한 위치는 앱의 **설정 → 저장 파일 위치**에서 확인합니다. Windows의 기본 사용자 데이터 폴더는 다음과 같습니다.

```text
%APPDATA%\Daynote\
```

| 파일 | 용도 |
|---|---|
| `calendar.json` | 현재 날짜별 일정·TODO와 체크 상태 |
| `calendar.json.bak` | 직전 정상 저장본 |
| `preferences.json` | 선택한 테마 |
| `window-state.json` | 창 크기·위치·최대화 상태 |

로그인 후 자동 실행 여부는 운영체제 설정으로 관리됩니다. 다른 PC로 옮겼을 때는 새 PC에서 다시 설정하세요.

### 다른 PC로 옮기거나 별도 보관하기

1. **자동 저장됨**을 확인한 뒤 앱을 종료합니다.
2. 설정에서 확인한 사용자 데이터 폴더를 다른 위치에 복사합니다.
3. 새 PC에서 Daynote를 설치하고 한 번 실행한 뒤 종료합니다.
4. 새 PC의 사용자 데이터 폴더에 보관한 파일을 복사하고 앱을 실행합니다.

창 위치가 새 PC의 화면 범위를 벗어나면 현재 화면에 맞게 보정합니다. 자동 백업은 같은 PC에 있는 직전 저장본 하나이며, 삭제 항목을 여러 단계로 되돌리는 기록은 아닙니다.

### 저장 파일 손상 시

`calendar.json`을 읽을 수 없으면 손상된 원본을 별도로 보존하고 정상 백업으로 복원합니다. 백업도 읽을 수 없으면 기존 기록을 덮어쓰지 않고 앱을 종료합니다. 오류 안내에 나온 저장 위치와 따로 보관한 백업을 확인하세요.

## 문제 해결

| 상황 | 확인할 내용 |
|---|---|
| 앱이 업데이트되지 않은 것 같음 | 실행 중인 앱을 종료하고 새 설치파일로 같은 위치에 설치했는지, 설정의 버전이 1.2.0인지 확인 |
| 빈 곳을 눌러도 입력되지 않음 | 입력줄을 직접 클릭하거나 `(+)`로 입력란을 선택 |
| Tab으로 설명이 만들어지지 않음 | 첫 항목인지 확인하고, 위에 체크박스가 있는 새 항목에서 사용 |
| 캘린더에 일부 일정만 보임 | `+N개`는 숨겨진 일정 수이며 날짜를 선택하면 오른쪽에서 전체 확인 가능 |
| 할 일 개수가 예상과 다름 | 진행률은 내용이 있는 TODO 체크박스만 계산하며 설명·일정·빈 항목은 제외 |
| 저장 실패가 표시됨 | 저장 공간과 사용자 데이터 폴더의 접근 상태를 확인하고 상단 저장 표시로 재시도 |
| Excel 내보내기가 비어 있음 | 캘린더 날짜로 기간을 지정했는지, 일정이 아닌 TODO에 내용을 적었는지 확인 |
| 파일 덮어쓰기에 실패함 | 기존 Excel 파일을 닫거나 다른 이름·저장 위치로 다시 시도 |

개발 명령과 지원 플랫폼, 검증의 상세 범위는 [README](../README.md)와 [검증결과](검증결과.md)에 정리되어 있습니다.
