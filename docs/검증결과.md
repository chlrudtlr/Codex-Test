# 첫 버전 검증 결과

## 완료한 검증

- JavaScript 파일 11개 구문 검사.
- 날짜 계산, 진행률 집계, 설명의 연결 관계, 입력 데이터 검증 등 모델 검사 5개.
- 저장·백업·손상 복구·창 위치 보정 검사 4개.
- 실제 Windows Electron 앱에서 화면 검증 시나리오 4개 통과.
- Linux 가상 화면에서 같은 화면 검증 시나리오 4개 통과. 최종 창 복원 보완 후 저장·복원 시나리오도 재검증.
- Windows에서 최종 NSIS 설치파일 생성 완료.

## 화면 검증 범위

1. 한국어 텍스트, Enter·Tab 설명 입력, 자동 줄바꿈, 체크 완료, 진행률, 날짜별 독립 저장, 재실행 복원.
2. 긴 일정 제목의 말줄임, 숨겨진 일정 개수, 작은 창에서의 진행률 표시.
3. 설명의 체크박스 전환, 항목·설명 삭제와 실행 취소, IME 조합 중 Enter 처리, 설정 화면.
4. 자동 저장 대기 중 창 종료 시 마지막 입력 보존, 창 크기 복원, 복원 오차가 저장 크기에 누적되지 않는지 확인.

한글 IME 조합 이벤트 처리는 자동화로 검사했습니다. 실제 한글 입력기의 모든 조합 동작을 수동으로 검증한 것은 아닙니다.

## 남은 실사용 확인

- Windows 설치 마법사를 통한 실제 설치와 작업표시줄 고정.
- 설치된 앱의 자동 실행 설정 및 실제 로그아웃·로그인 후 실행.
- macOS 설치·실행.

Windows 소수 배율에서 Electron의 좌표 반올림으로 복원 크기에 1~2 DIP의 차이가 생길 수 있습니다. 앱은 이 차이가 재실행할 때마다 저장 크기에 누적되지 않도록 처리합니다. 관련 upstream 이슈: [electron/electron#55245](https://github.com/electron/electron/issues/55245).

설치파일에는 코드 서명 인증서가 적용되어 있지 않습니다. 테스트는 실제 사용자 기록과 분리된 임시 폴더를 사용했습니다.
